## 🚀 Featured Projects

### 🎮 Neon Drift
A one-button arcade drifting game with procedural tracks, neon effects, instant restarts, and a local best score.

**Built with:** Canvas · JavaScript · LocalStorage

### ⏱️ Focus Flow
A lightweight focus timer with session history, daily streaks, and a seven-day chart.

**Built with:** SVG · Web Audio · LocalStorage

### 🧩 Snippet Vault
A keyboard-first snippet manager with search, syntax highlighting, and local import/export.

**Built with:** JavaScript · CSS · LocalStorage

### 🌦️ Weather Window
A responsive weather dashboard with hourly and seven-day forecasts using the free Open-Meteo API.

**Built with:** JavaScript · Open-Meteo API · Geolocation

### 🎨 CSS Lab
An interactive space for experimenting with CSS and visual ideas directly in the browser.

**Built with:** HTML · CSS · JavaScript
