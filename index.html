        Hi, I'm Umbra

        I'm a developer who learned the web by breaking it on purpose. That curiosity turned into a habit: build a small thing, learn one new trick, ship it, repeat.

        I like projects where code, design and play meet. A timer that feels calm. A game you can restart in a heartbeat. A portfolio that you can actually use.

        When I'm not coding, I'm gaming, editing videos, or sketching the next idea on whatever's nearby.

        Questions

        Before we build.

        Can you build a website for a phone-first audience?

        Yes. I design around small screens first and then scale the layout up for tablets and desktop.

        Can I use my own domain?

        Yes. Domain setup is included in the Pro and Ultimate packages. The domain registration or renewal cost itself is separate if the domain is paid.

        Can you make a 3D website?

        Yes. The Ultimate package can include interactive 3D or Three.js experiences when the project needs them.

        How do I start a project?

        Use the project form below, choose the closest budget, and describe what you want to build. It opens an email with the details ready to send.

        Got something worth building?

        Tell me what you're making: a site, an app, a game jam team-up or a video idea. I usually reply within a couple of days.
